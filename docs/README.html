Documentation overview

The canonical navigation entry point is the OKF v0.2 documentation index. This page provides a short audience-oriented overview and remains at its historical path for existing links.

  • New visitors and users: start with the project README, then use the user guide index for current support boundaries and user-facing guidance.
  • Contributors: read the contributor guide and documentation policy before changing source or docs.
  • Architects and implementers: use the architecture index, including the numbered architecture decision records.
  • Language and API researchers: use the reference index and the reference source register. Keep dialect and version evidence separate.
  • Testing and verification: start with the testing index and corpus instructions.
  • Source reviewers: use the research index for page-addressable evidence, extraction audits, and open questions.
  • Documentation authors: use the template index for reusable guide and reference structures.

The Markdown concepts under docs/ are the canonical editable source. Static website pages are generated from these concepts during CI and deployment; do not edit generated HTML or maintain a second copy of a concept in site/.
