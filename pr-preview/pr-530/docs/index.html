Research and evidence

  • Research - Source reviews, inventories, and evidence notes.
  • Amiga GFA BASIC command catalogue - Entry point for the extracted Amiga command/function lists, detailed book and OS API extraction, structured inventories, version evidence, and count definitions.
  • Amiga GFA BASIC language population policy - Maintainer-approved denominator, normalization, exclusions, evidence and implementation counting rules for issue #307.
  • Amiga GFA BASIC Chapter 7 program-handling evidence - Page-cited base-manual inventory for program control, procedures, and error handling; 3.52 probes are a separate evidence dimension.
  • Amiga GFA BASIC Chapter 8 graphics compatibility evidence - Page-cited graphics inventory, 3.5 PCOLOR reconciliation, and 3.52 probe coverage boundary.
  • Amiga GFA BASIC Chapter 9 event/window evidence - Page-cited event, menu, screen, window and requester inventory; isolates the documented 3.5 OPENW variant.
  • Amiga GFA BASIC Chapter 10 advanced programming evidence - Page-cited advanced programming inventory; keeps Amiga-specific facilities and 3.0/3.5/3.52 evidence separate.
  • Amiga GFA BASIC Chapter 11 system-routine evidence - Page-cited inventory of seven Amiga OS library groups; distinguishes 3.0 base-manual APIs, 3.5 addendum evidence, and 3.52 runtime probes.
  • Amiga GFA BASIC Chapter 12 appendix and index evidence - Page-cited reference-table inventory, AmigaDOS errors, and command/system-call indexes; preserves 3.0/3.5/3.52 evidence boundaries.
  • Amiga GFA BASIC test output - Native file-output observation and proposed batch result protocol.
