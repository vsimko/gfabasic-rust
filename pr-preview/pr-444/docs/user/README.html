User Guide

User documentation

Audience: People evaluating or using the planned GFA BASIC compiler.

Status: User documentation is limited because source compilation and runtime behavior are not implemented. The minimal CLI supports help and version output only; build and check do not compile source.

Current status

The repository includes a minimal gfabasic executable, but it supports only help and version output. The build and check commands explicitly report that source compilation is unavailable. There is no installation package or supported GFA BASIC dialect/API profile. Do not attempt to follow build commands copied from another GFA BASIC implementation.

Start with the project README for the current project direction and limitations. Use the compatibility matrix for the current support status.

The compiler library includes a source-map diagnostic model and human-readable renderer, but no GFA BASIC frontend or CLI command currently emits compiler diagnostics. See Understanding compiler diagnostics for the proposed user-facing vocabulary.

Research is not a support claim

The language and API reference notes record source-backed research and unresolved questions. Their presence does not mean that a feature is implemented, tested, or supported by this project. Amiga and Atari ST material is kept separate.
